# Systems Analysis and Design: SPL Application Improvement

## Overview

Group systems-analysis project focused on issues in the SPL logistics application. The project examined the current environment, collected stakeholder input, defined requirements, compared solution alternatives, and modeled current and proposed data flows.

## Objective

Identify operational and customer-facing issues in shipment handling, tracking, notification, and information accuracy, then recommend a feasible system improvement.

## My Contribution

Co-authored the group project. The source report identifies Renad Alghamdi as a group member; it does not specify individual work allocation.

## Tools/Technologies

- Semi-structured stakeholder interview
- Questionnaire
- SWOT analysis and 5 Whys analysis
- Gap analysis
- Requirements analysis
- Weighted scoring and feasibility analysis
- Context diagrams and data-flow diagrams (DFDs)

## Methodology

1. Documented SPL's organizational environment, systems, and stakeholders.
2. Collected primary input through an interview and questionnaire.
3. Analyzed the current process using gap analysis, SWOT, and 5 Whys.
4. Defined the problem, scope, issues, objectives, requirements, and constraints.
5. Compared proposed web, mobile-app, and desktop-system alternatives using weighted scoring.
6. Assessed operational and technical feasibility and modeled current and proposed data flows.

## Key Work

- Identified issues related to linking national addresses to shipments, invoice accuracy, shipment-status notifications, incoming-package information, complaint tracking, and estimated delivery dates.
- Developed functional and non-functional requirements including secure, safe, and easy-to-use service capabilities.
- Proposed integration and communication capabilities to improve access to package information and customer tracking.
- Produced As-Is and To-Be system representations with context and data-flow diagrams.

## Results/Findings

The analysis concluded with a recommended system alternative based on weighted evaluation and feasibility discussion. The documented proposal focuses on improving shipment information, automatic notifications, customer tracking, invoice review, and communication about incoming packages. These are recommended improvements, not implemented production results.
