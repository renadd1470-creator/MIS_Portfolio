## Skills supported by this work

- Business and systems analysis: requirements discovery, stakeholder research, problem definition, feasibility assessment, and solution evaluation.
- Data and BI analysis: data preparation, data-quality assessment, descriptive statistics, regression analysis, KPI design, and dashboard communication.
- Process improvement: process mapping, bottleneck analysis, To-Be redesign, workflow automation concepts, and cycle-time analysis.
- Data management: conceptual and logical data modeling, normalization, relational database implementation, SQL, constraints, and analytical queries.
- UX and product design: design thinking, user research, personas, user journeys, wireframes, prototypes, usability testing, and iterative improvement.
