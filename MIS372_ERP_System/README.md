# Enterprise Systems: Coca-Cola ERP Analysis

## Overview

Group enterprise-systems analysis of Coca-Cola's core functions and cross-functional order-fulfillment process. The work used process models to examine how an ERP system could address coordination, visibility, and data-entry issues.

## Objective

Map organizational functions and a cross-functional process, identify process-improvement opportunities, and assess ERP capabilities, selection considerations, and expected organizational outcomes.

## My Contribution

Co-authored the group project. The source report identifies Renad Alghamdi as a group member; it does not specify individual work allocation.

## Tools/Technologies

- Enterprise resource planning (ERP) concepts
- Landscape model
- Swimlane process mapping
- Before-and-after process comparison

## Methodology

1. Documented the organization's core, management, and support functions in a landscape model.
2. Mapped the order-fulfillment process across sales, warehouse, logistics, and accounting activities.
3. Identified manual-data-entry, information-flow, order-tracking, picking/packing, and inventory-visibility issues.
4. Evaluated the functional capabilities and selection considerations of an ERP system.
5. Compared the current process with the proposed ERP-enabled process.

## Key Work

- Developed a Coca-Cola landscape model covering sales and distribution, development and production, supply-chain management, marketing, and supporting functions.
- Created a cross-functional swimlane view of order fulfillment.
- Analyzed risks associated with manual order entry, limited real-time shipment tracking, disconnected departmental information, picking/packing errors, and inventory visibility.
- Described how ERP-enabled integration and real-time information could address the identified gaps.

## Results/Findings

The analysis identified an integrated ERP approach as a way to reduce manual handoffs, improve visibility of orders and shipments, and support more consistent information sharing across functions. These are proposed process improvements from the project analysis, not measured implementation results.
